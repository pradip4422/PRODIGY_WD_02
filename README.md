# PRODIGY_WD_02 - Stopwatch Web App

Task-02 of the Prodigy InfoTech Web Development Internship. A responsive stopwatch with lap history, built with plain HTML, CSS and JavaScript.

## Features
- Start, Pause (Resume), Reset and Lap buttons
- Time shown as HH:MM:SS with milliseconds
- Lap history with lap number, lap time and total time
- Clear Laps button
- Buttons are disabled when their action does not apply
- Accurate timing using timestamps (performance.now), no drift
- Only one timer can run at a time
- Responsive dark navy design for mobile, tablet and desktop

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (no libraries or frameworks)

## How to Run
1. Download or clone this repository.
2. Open `index.html` in any browser, or use the VS Code Live Server extension.

## Project Structure
```
PRODIGY_WD_02/
├── index.html

└── README.md
```

## Deploy with GitHub Pages
1. Push the project to a public repository named `PRODIGY_WD_02`.
2. Go to Settings, then Pages.
3. Under Source, choose the `main` branch and the `/ (root)` folder, then click Save.
4. After 1-2 minutes, the site is live at `https://YOUR-USERNAME.github.io/PRODIGY_WD_02/`.
